# Contributing

Thanks for helping improve StartTiny.

## Development

This project intentionally uses plain HTML, CSS and JavaScript so it stays easy to understand, fork and host.

1. Fork the repository.
2. Create a feature branch.
3. Make a focused change.
4. Test the app in a current desktop browser and a mobile-sized viewport.
5. Open a pull request explaining what changed.

Please avoid adding unnecessary frameworks, trackers or external services without discussion.

## Good first contributions

- Accessibility improvements
- Keyboard shortcuts
- Better mobile layouts
- Translations
- New timer presets
- Improved task sorting
- Bug fixes
