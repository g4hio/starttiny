How to Stop Procrastinating on a Task

You rarely need more motivation first. You need a smaller first action. This page is a practical guide. StartTiny is the free anti-procrastination app you can use with it.

Open StartTiny and start tiny

Why starting feels harder than doing

Procrastination often happens when a task is vague, large, boring, or emotionally loaded. The brain treats “write the essay” as a threat. “Open the document and write one ugly sentence” is small enough to begin.

Reduce the starting requirement. Do not wait until the plan is perfect.

A five-step way to begin

  1. Name one next action. If you cannot do it in two minutes, shrink it.
  2. Dump competing thoughts. Reminders and worries can sit in notes so they stop interrupting.
  3. Match the timer to your energy. Tired or overwhelmed? Use 10 minutes. Okay? Use 25. Energized? Use 40–50.
  4. Start the timer before you feel ready. Action creates motivation more reliably than the reverse.
  5. Count a short session as success. Momentum matters more than a heroic first attempt.

How StartTiny helps

Use Help Me Start when the task still feels too big. The tool suggests a smaller first step, such as opening the file or writing one draft line.

If you are still stuck

  • Change the environment: close extra tabs, stand up, or move the phone away.
  • Do the easiest two minutes only. Stopping is allowed. Starting is the win.
  • If the task is actually several tasks, split it and do only step one.
