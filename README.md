# StartTiny

### Start tiny. Stay focused.

**[Try StartTiny](https://g4hio.github.io/starttiny/)**

StartTiny is a free, open-source **anti-procrastination app**, **procrastination timer**, and **student focus timer** for students, professionals, and everyday tasks. It combines a flexible study timer, task management, optional deadlines, task sorting, a private brain-dump notebook, energy check, focus mode, and small prompts that help you get started.

## Why StartTiny?

You do not always need more motivation. Sometimes you need a smaller first step. StartTiny is designed to reduce the friction between deciding to do something and actually beginning.

## Features

- Flexible focus and break timer
- Quick presets: 10/2, 25/5, 40/10, 50/10
- Custom focus and break lengths
- Tasks with priority and optional deadlines
- Overdue, due-today, and due-soon indicators
- Smart and manual task sorting
- Individual private brain-dump notes
- Help Me Start prompts
- Focus mode
- Energy check
- Local browser storage — no account or backend

## For students

Use StartTiny for homework, revision, essays, coding, reading, exam preparation, research, projects, and long-term assignments.

## For adults and work

Use it for work projects, writing, programming, applications, planning, personal projects, household tasks, and anything you keep putting off.

## Privacy

StartTiny has no required account, backend, advertising, or analytics. Tasks, notes, and settings are stored in the browser's local storage.

## Run locally

No build step is required. Clone or download the repository and open `index.html`. For browser notifications, use a local web server or deploy through GitHub Pages.

## GitHub Pages

Use **Settings → Pages → Deploy from a branch → `main` → `/ (root)`**.
