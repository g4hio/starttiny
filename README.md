# StartTiny

## Start tiny. Stay focused.

**StartTiny is a free, open-source anti-procrastination and focus tool for students, professionals, and anyone who struggles to get started.**

### 🚀 [Use StartTiny](https://g4hio.github.io/starttiny/)

StartTiny is built around one simple idea:

> You do not always need more motivation. Sometimes you need a smaller first step.

It combines a flexible focus timer, task management, optional deadlines, task sorting, a private brain-dump notebook, and small prompts that help turn “I should do this” into an action you can actually begin.

## Features

### ⏱ Flexible focus timer

- 10 / 2
- 25 / 5
- 40 / 10
- 50 / 10
- Custom focus and break lengths
- Optional browser notifications
- Focus mode for a simpler working view

### ✅ Tasks and deadlines

- High, medium, and low priority
- Optional deadlines
- Completion tracking
- Overdue and due-today indicators
- Smart sorting
- Deadline, priority, newest, oldest, and completion sorting

### 📝 Private brain dump

Create individual notes for ideas, reminders, distractions, quick planning, links, and anything else competing for your attention. Notes can be deleted individually.

### 🧠 Help Me Start

When a task feels too large, StartTiny suggests a smaller next action.

### 😴 Energy check

Choose your current energy level and use the suggested approach to reduce the starting barrier.

## For students

StartTiny works for homework, revision, essays, reading, coding, exam preparation, coursework, applications, and long-term assignments.

Read the [free study timer guide](https://g4hio.github.io/starttiny/study-timer/) or the [student productivity page](https://g4hio.github.io/starttiny/student-productivity/).

## For work and everyday life

Use StartTiny for writing, programming, research, projects, planning, household tasks, personal projects, applications, and other jobs you keep postponing.

See the [procrastination timer](https://g4hio.github.io/starttiny/procrastination-timer/) and [procrastination guide](https://g4hio.github.io/starttiny/procrastination-help/).

## Pomodoro alternative

StartTiny can be used like a Pomodoro timer, but it is not locked to a single interval. You can choose presets or create custom focus and break lengths.

See the [Pomodoro alternative page](https://g4hio.github.io/starttiny/pomodoro-alternative/).

## Privacy

StartTiny does not require an account and has no application backend. Tasks, notes, and settings are stored in the browser's local storage. The project does not include analytics or advertising code.

## Search and crawler policy

The repository contains a permissive `robots.txt` with `User-agent: *` and `Allow: /`, plus a `sitemap.xml` listing the public pages. The site does not intentionally block public search crawlers through `robots.txt`.

Search engines and AI systems make their own crawling, indexing, and ranking decisions; a permissive robots file does not guarantee inclusion or recommendations.

## Run locally

No build step is required.

1. Clone or download the repository.
2. Open `index.html` in a browser.
3. For browser notification support, serve the directory from a local web server or deploy it through GitHub Pages.

## GitHub Pages

1. Create a public GitHub repository.
2. Upload the repository contents so `index.html`, `app.js`, `styles.css`, `robots.txt`, and `sitemap.xml` are in the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save.

The live site will be available at your GitHub Pages URL.
